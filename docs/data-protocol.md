# Data integrity protocol

1. Resolve and record an immutable commit for the official Hugging Face dataset.
2. Read only an allowlist of original source fields and expert targets from Parquet;
   GPT fields, explanation-correctness fields and the old training flag are discarded.
3. Sort unique string patient IDs, shuffle the array with NumPy default_rng(42), and
   allocate the first 37 / next 8 / remaining 8 to train / validation / test.
4. Publish the manifest with patient IDs, per-patient/per-split row counts, source commit,
   raw-file SHA256 and NumPy version. No patient appears in multiple splits.
5. Preserve numbered source sentences; reject unknown labels and dangling gold evidence IDs.
6. Export only `input` (note, type, criterion) and `target` (expert label and sentence IDs)
   plus original annotation/patient/trial IDs for traceability.
7. The test file is prepared mechanically but never sampled, profiled semantically, used
   for prompt development, or scored during setup. No test labels appear in setup summaries.
   A future final evaluator must explicitly authorize test use after configuration freeze.

The supervised output currently contains label and evidence IDs. Grounded explanations
and extracted text must be added by the inference pipeline using the original note;
there is no expert explanation target, and GPT explanations must not be repurposed.
Dataset sentence IDs are preserved, not regenerated by a sentence tokenizer.

Evidence metric convention for the implemented before/after evaluation: micro scores accumulate
TP/FP/FN over all examples; macro averages each example. If gold and prediction are both
empty, per-example P/R/F1 = 1; if exactly one is empty, P/R/F1 = 0. If micro denominators
are all zero, report the no-evidence condition explicitly rather than imply retrieval success.
Invalid structured outputs contribute zero to per-example scores and an empty usable
predicted set to micro counts; invalid counts are reported separately. No fabricated
sentence IDs are added. This is an explicit project choice, not a convention prescribed
by the PDF. See `docs/training-workflow.md` for the full fixed-label classification policy.
